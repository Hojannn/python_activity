Project Overview

This e-commerce platform was created by a student as a final project, built using Flask, SQLAlchemy, and Tailwind CSS. It demonstrates a fully functional online store with product management, user authentication, cart, and checkout systems.

The system is currently still under development, with ongoing improvements being made to the UI, performance, and feature set. It serves as a practical demonstration of full-stack web development skills.

Future improvements are planned including payment gateway integration, email notifications, advanced filtering, and a more robust admin panel.
